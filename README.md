# usewit.dev

The website for [Wit](https://github.com/Vorinos/Wit).

- `/` is the landing page (`index.html`).
- `/app/` is the Wit app itself, running in the browser. It's a copy of `app/index.html` from Vorinos/Wit, with the tab icon added. The **Sync web app** workflow refreshes it every 6 hours, or straight away from the Actions tab.

Hosted on GitHub Pages; `CNAME` holds the domain.
